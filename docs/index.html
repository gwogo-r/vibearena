MVP · слепое A/B-сравнение

VibeArena

Помогает маркетологу выбрать модель генерации изображений — вслепую, с учётом цены, скорости и качества русскоязычных креативов, а не по бренду провайдера.

Проблема

В VibeMarketolog Agent API доступно два десятка моделей генерации изображений от разных провайдеров. Обычному маркетологу сложно понять, какую использовать для баннера, карточки товара, фотореализма или изображения с русским текстом — каталог показывает технические параметры, но не отвечает на вопрос «что лучше для моей задачи?».

Было

Список моделей с ценами и параметрами. Выбор — на глаз, по названию или репутации провайдера.

Стало

Один промпт → две модели параллельно → слепое голосование → раскрытие цены, модели и времени только после выбора.

Как это работает

1. Настройка

Категория задачи, промпт, опционально — фото товара для image-editing моделей. Каталог моделей (цена, форматы, seed) загружается динамически.

2. Смета и генерация

Бесплатная предварительная оценка стоимости, подтверждение — и только потом параллельный платный запуск обеих моделей.

3. Голос и раскрытие

Слепой выбор лучшего результата. После голоса — название модели, реальная цена, время генерации и статистика по категориям.

Опционально: свой товар вместо генерации с нуля

Загружаете фото товара — сравниваете image-editing модели. Товар остаётся как есть, меняется только сцена вокруг него. Ниже — реальный прогон: одно исходное фото, два результата от разных моделей одновременно.

Почему слепое сравнение

Когда пользователь заранее знает название модели, бренд и репутация провайдера влияют на оценку сильнее, чем реальное качество результата. Механика — как в Artificial Analysis Image Arena и LMArena, только заточена под задачи русскоязычного маркетолога: цена в рублях, реальное время генерации и качество русского текста на изображении.
